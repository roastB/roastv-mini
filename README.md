# roastv-mini
Roast V — a tiny desk robot with an ASCII face, built with ROS 2, ESP32-S3 and Raspberry Pi 5

직접 그린 캐릭터 **Roast V**를 키 17cm 안팎의 데스크 로봇으로 만드는 개인 프로젝트예요.
화면 얼굴(아스키 표정), 2축 목, 운동화 속 바퀴를 ROS 2와 AI로 움직여요.

```
      (o)        안테나 상태등 · WS2812B
   .-------.
  [| (^_^) |]    얼굴 화면 · ESP32-S3-Touch-LCD-2   이어컵 = 스피커
   '-------'     ID 2 · 목 상하 (머리 아래)
      | |        ID 1 · 목 좌우 (몸통 위)
   /-------\
   | Pi 5  |     후드티 몸통 · Raspberry Pi 5 · ReSpeaker Lite
   \-------/
    [_] [_]      운동화 속 바퀴 · ID 3 왼쪽 / ID 4 오른쪽 + 볼 캐스터
```

## 하드웨어

| 부위 | 부품 |
|---|---|
| 얼굴 | Waveshare ESP32-S3-Touch-LCD-2 (2" 240×320, QMI8658 IMU) |
| 목 | SC09 버스 서보 ×2 — ID 1 좌우, ID 2 상하 |
| 바퀴 | SC09 버스 서보 ×2 (모터 모드) — ID 3 왼쪽, ID 4 오른쪽, 뒤쪽 볼 캐스터 |
| 두뇌 | Raspberry Pi 5 + Camera Module 3 Wide |
| 귀·입 | Seeed ReSpeaker Lite + 28mm 스피커 ×2 |
| 전원 | Pi 27W USB-C + 서보 DC 6V 5A (꼬리 케이블, 배터리 없음) |

## 폴더 구조

```
roastv-mini/
├── docs/
│   ├── design/      디자인 문서: 비율표, 기능 매핑, 표정 시트, 제스처, 성격
│   ├── hardware/    시스템 지도, 부품표, 배선, 전원, Pi 세팅
│   └── images/      목업·빌드 사진
├── cad/
│   └── stl/         출력용 STL (head/ neck/ body/ base/)
├── firmware/
│   └── face/        ESP32-S3 얼굴 프로그램 (PlatformIO)
├── ros2_ws/
│   └── src/         ROS 2 패키지 (roastv_*)
└── tools/           혼자 실행하는 스크립트
```

## 작업 규칙

- 커밋 메시지는 강의 회차로 시작해요. 예: `W01-2 기능 매핑표 v0`
- 토요일 빌드를 마치면 그 주 태그를 붙여요. 예: `git tag w01`
- ROS 2 빌드 결과(`ros2_ws/build` `install` `log`)와 데이터(`data/`)는 git에 올리지 않아요.
- 치수 단위는 mm, 서보 각도는 도(°)로 적어요.
